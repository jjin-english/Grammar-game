ℹ️ 문법 핵심 정리

provided that = “~라는 조건이라면 / 반드시 ~해야만”
→ if보다 조건을 더 강하게 강조하는 접속사예요.
→ that은 생략 가능합니다.
→ 앞뒤 절 순서는 자유롭습니다.

본문 예문: eucalyptus is only able to reproduce provided that there is fire.
(유칼립투스는 불이 있을 때만 번식할 수 있다.)
